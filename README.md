## ✨ 核心特色
- **极简设计**：中央半透明毛玻璃卡片设计，拒绝任何多余的视觉干扰。
- **智能搜索**：内置高效搜索栏，支持一键键入跳转。
- **必应壁纸**：每日自动同步 Bing 官方高清壁纸，天天都有新心情。
- **环境自适应**：JavaScript 智能检测背景亮度，全自动切换浅色/深色 Logo。
- **快捷导航**：集成常用高频网站图标，一键直达。
